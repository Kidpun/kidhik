# Настройка Groq AI

Groq - это бесплатная нейросеть с очень быстрыми ответами и щедрым бесплатным tier.

## Как получить API ключ:

1. Перейдите на https://console.groq.com/
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в раздел "API Keys" (https://console.groq.com/keys)
4. Нажмите "Create API Key"
5. Скопируйте ключ (он показывается только один раз!)

## Настройка в боте:

1. Откройте файл `.env` в корне проекта
2. Добавьте строку:
   ```
   GROQ_API_KEY=ваш_ключ_здесь
   ```
3. Сохраните файл
4. Перезапустите бота

## Использование:

После настройки используйте команду:
```
.ai <ваш вопрос>
```

Примеры:
- `.ai Привет, как дела?`
- `.ai Объясни что такое Python`
- `.ai Напиши код для сортировки массива`
- `.ai Что такое машинное обучение?`

## Доступные модели:

По умолчанию используется `llama-3.1-70b-versatile` (очень мощная модель).

Вы можете изменить модель в `.env`:
```
GROQ_MODEL=mixtral-8x7b-32768
```

Доступные модели:
- `llama-3.1-70b-versatile` - самая мощная (рекомендуется)
- `llama-3.1-8b-instant` - быстрая, но менее мощная
- `mixtral-8x7b-32768` - хороший баланс
- `gemma-7b-it` - быстрая модель от Google

## Лимиты:

Groq предоставляет очень щедрый бесплатный tier:
- До 30,000 запросов в минуту
- Быстрые ответы (обычно < 1 секунды)
- Поддержка длинных контекстов

## Примечание:

Если вы не настроите API ключ, команда `.ai` будет показывать ошибку с инструкцией по настройке.
