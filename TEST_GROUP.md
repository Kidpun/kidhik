# Тестирование бота в группах

## ✅ Бот настроен для работы везде

Код не имеет ограничений на типы чатов. Все команды должны работать в:
- Личных сообщениях ✅
- Группах ✅
- Супергруппах ✅

## 🔍 Как проверить:

### 1. Добавьте бота в группу:
```
1. Откройте группу в Telegram
2. Нажмите на название группы → "Добавить участников"
3. Найдите вашего бота (@HIKIKIDbot) и добавьте
```

### 2. Дайте боту права:
```
1. Откройте настройки группы
2. Участники → Найдите бота
3. Нажмите на бота → "Изменить права"
4. Включите:
   ✅ Отправлять сообщения
   ✅ Удалять сообщения (для .откат)
   ✅ Редактировать сообщения (для .снос)
```

### 3. Проверьте работу:
Отправьте в группе:
- `.откат` - бот должен начать отправлять фразы
- `.троль` - бот должен начать троллить
- `.снос` - бот должен показать прогресс
- `.стоп` - бот должен остановить процессы

## ⚠️ Если бот не отвечает в группе:

1. **Проверьте логи** - откройте `kidhik.log` и посмотрите, есть ли ошибки
2. **Проверьте права бота** - бот должен иметь право отправлять сообщения
3. **Проверьте, что бот добавлен** - бот должен быть участником группы
4. **Проверьте, что команда отправлена правильно** - команда должна начинаться с точки: `.откат`

## 📝 Логи для отладки:

В логах вы должны увидеть:
```
User <id> started .откат in chat <chat_id> (type: group)
```
или
```
User <id> started .откат in chat <chat_id> (type: supergroup)
```

Если видите `type: private` - значит команда была вызвана в личных сообщениях, а не в группе.

## 🐛 Если проблема остаётся:

1. Перезапустите бота
2. Проверьте, что бот запущен и работает
3. Отправьте команду в группе и проверьте логи
4. Убедитесь, что бот не заблокирован в группе
