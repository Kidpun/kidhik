# Быстрый старт KidHik

## 🚀 Установка и запуск

1. **Установите зависимости:**
```bash
cd /Users/kid/Desktop/python/scr/kidhik
pip install -r requirements.txt
```

2. **Создайте файл `.env`:**
```bash
cp .env.example .env
```

3. **Заполните `.env` файл:**
```
BOT_TOKEN=ваш_токен_бота_от_BotFather
```

4. **Запустите бота:**
```bash
python main.py
```

## 📝 Команды

Все команды начинаются с точки:

- `.откат` - Удаляет ваше сообщение и начинает отправлять случайные фразы
- `.троль` - Отправляет фразы из файла `text/troll.txt`
- `.снос` - Показывает прогресс "сноса" от 0% до 99%
- `.музыка` - Показывает текущий трек из Spotify (требует настройки)
- `.стоп` - Останавливает все активные процессы

## ⚙️ Настройка Spotify (опционально)

Для команды `.музыка` нужно:

1. Создать приложение на https://developer.spotify.com/dashboard
2. Получить Client ID и Client Secret
3. Добавить в `.env`:
```
SPOTIFY_CLIENT_ID=ваш_client_id
SPOTIFY_CLIENT_SECRET=ваш_client_secret
SPOTIFY_REDIRECT_URI=http://localhost:8888/callback
```

**Примечание:** Настройка токенов пользователей будет доступна в будущих версиях через личные сообщения с ботом.

## 📁 Структура

- `commands/` - Все команды бота
- `handlers/` - Обработчики сообщений и команд
- `utils/` - Утилиты (менеджер пользователей, Spotify, кеш сообщений)
- `config/` - Конфигурация
- `text/` - Текстовые файлы (troll.txt)

## 🔧 Логи

Логи сохраняются в:
- Консоль (stdout)
- Файл `kidhik.log`

## ⚠️ Важно

- Бот работает с несколькими пользователями одновременно
- Каждый пользователь может иметь только один активный процесс
- Команда `.стоп` останавливает все активные процессы пользователя
- Все команды работают в любых чатах, где у бота есть права
