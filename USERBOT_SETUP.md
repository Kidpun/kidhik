# Настройка Userbot KidHik

## 🔧 Что изменилось:

Бот переделан на **userbot** (Telethon) - теперь работает **от имени пользователя** и может:
- ✅ Читать сообщения во **ВСЕХ** чатах пользователя
- ✅ Отправлять сообщения от имени пользователя
- ✅ Имитировать активность пользователя
- ✅ Работать в группах, личных сообщениях, каналах

## 📋 Требования:

1. **API credentials от Telegram:**
   - Получите `api_id` и `api_hash` на https://my.telegram.org/apps
   - Войдите в аккаунт Telegram
   - Создайте приложение
   - Скопируйте `api_id` и `api_hash`

2. **Python 3.8+**

## 🚀 Установка:

1. **Установите зависимости:**
```bash
cd ~/kidhik
pip3 install -r requirements.txt
```

2. **Настройте .env файл:**
```bash
# Добавьте в .env:
API_ID=ваш_api_id
API_HASH=ваш_api_hash

# Опционально (для Spotify):
SPOTIFY_CLIENT_ID=your_spotify_client_id
SPOTIFY_CLIENT_SECRET=your_spotify_client_secret
```

3. **Запустите userbot:**
```bash
python3 main.py
```

4. **При первом запуске:**
   - Введите номер телефона (с кодом страны, например: +79991234567)
   - Введите код из Telegram
   - Если включена 2FA, введите пароль
   - Сессия сохранится в `session/kidhik.session`

## ✅ Использование:

После запуска userbot будет:
- Слушать **все** ваши чаты
- Реагировать на команды: `.откат`, `.троль`, `.снос`, `.музыка`, `.стоп`
- Отправлять сообщения **от вашего имени**

## ⚠️ Важно:

- Userbot работает от вашего имени - все сообщения отправляются как от вас
- Сессия хранится в `session/kidhik.session` - не делитесь этим файлом!
- Userbot имеет доступ ко всем вашим чатам
- Используйте на свой риск

## 🔒 Безопасность:

- Храните `.session` файл в безопасности
- Не делитесь `api_id` и `api_hash`
- Регулярно проверяйте активные сессии в настройках Telegram
