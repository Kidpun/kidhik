# Настройка бота для работы в группах

Бот **уже настроен** для работы везде (личные сообщения, группы, супергруппы).

## ✅ Что уже работает:

- Все команды (`.откат`, `.троль`, `.снос`, `.музыка`, `.стоп`) работают в любых чатах
- Бот может отправлять сообщения везде, где у него есть права
- Нет ограничений на типы чатов

## 🔧 Настройка для групп:

### 1. Добавьте бота в группу:
- Откройте группу в Telegram
- Добавьте бота через поиск (@ваш_бот)
- Или используйте ссылку: `https://t.me/ваш_бот?startgroup=`

### 2. Дайте боту права:
Бот должен иметь права на:
- ✅ **Отправку сообщений** (обязательно)
- ✅ **Удаление сообщений** (для команды `.откат`)
- ✅ **Редактирование сообщений** (для команды `.снос`)

### 3. Проверка работы:
Отправьте в группе любую команду:
- `.откат` - бот начнёт отправлять фразы
- `.троль` - бот начнёт троллить
- `.снос` - бот покажет прогресс
- `.музыка` - бот покажет текущий трек (если настроен)
- `.стоп` - бот остановит все процессы

## ⚠️ Возможные проблемы:

### Бот не отвечает в группе:
1. Проверьте, что бот добавлен в группу
2. Проверьте права бота (должен иметь право отправлять сообщения)
3. Проверьте логи бота (`kidhik.log`)

### Ошибка "bot was blocked by the user":
- Пользователь заблокировал бота
- Бот не может отправлять сообщения этому пользователю

### Ошибка "chat not found":
- Бот не добавлен в группу
- Или группа была удалена

## 📝 Логирование:

Все действия бота логируются в:
- Консоль (при запуске)
- Файл `kidhik.log`

Если бот не работает в группе, проверьте логи на наличие ошибок.
